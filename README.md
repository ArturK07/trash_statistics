# Прогнозно-аналитическая система мониторинга отходов

Учебный проект по дисциплине «Прогнозно-аналитические системы».

Система предназначена для прогнозирования суточной массы отходов по объекту переработки и категории, а также для оценки будущей загрузки объекта относительно его мощности.

## Цель проекта

Помочь диспетчеру вывоза или руководителю объекта планировать загрузку мощностей и заранее выявлять даты возможного превышения установленного порога.

## Прогнозируемые показатели

- Суточная масса отходов по объекту и категории, тонн/сутки.
- Расчётная загрузка объекта, % от суточной мощности.

Загрузка рассчитывается по формуле:

`загрузка, % = прогнозируемая масса / суточная мощность объекта × 100`

## Планируемые компоненты

- Загрузка данных как минимум из двух разнородных источников.
- Обработка слабоструктурированных записей о событиях, влияющих на вывоз.
- Хранение исходных и обработанных данных.
- Инкрементальная и идемпотентная загрузка с журналированием запусков.
- Подготовка календарных, лаговых, оконных и событийных признаков.
- Сравнение прогнозных моделей отдельным скриптом.
- Объяснение выбранного прогноза отдельным скриптом.
- Симуляция поступления новых данных и контроль изменения распределений.
- Веб-интерфейс для планирования загрузки, просмотра качества моделей, журналов и результатов контроля данных.

Состав технологий может уточняться по мере реализации проекта.

## Структура проекта

Структура будет пополняться по этапам. Планируемые основные каталоги:

- `src/` — код загрузки, обработки, моделирования и интерфейса.
- `scripts/` — запускаемые скрипты обучения, сравнения и объяснения моделей.
- `config/` — конфигурация проекта.
- `data/` — локальные данные, не включаемые в Git.
- `artifacts/` — генерируемые результаты анализа и прогнозирования.
- `logs/` — журналы работы приложения.

## Запуск

Инструкция по установке зависимостей и запуску будет добавлена после создания модулей приложения.

## Данные и ограничения

В проекте используются только открытые или синтетические данные. Персональные данные не используются.

Новые порции данных могут подаваться в учебных целях симуляцией. Обнаружение изменения данных не запускает автоматическое переобучение модели.
