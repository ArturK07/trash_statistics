# Прогнозно-аналитическая система мониторинга образования отходов и загрузки объектов переработки

Учебный проект по разработке системы, которая анализирует образование отходов и загрузку объектов переработки, строит прогнозы и предоставляет средства мониторинга.

На текущем этапе реализованы генерация демонстрационных данных, их проверка и подготовка временных выборок, а также скриптовое сравнение моделей. Пользовательский интерфейс, хранилище SQLite и симуляция дрейфа данных запланированы для следующих этапов.

## Текущий статус

Реализовано:

- генерация синтетических данных об отходах и операционных событиях;
- проверка исходных данных и сохранение отчёта аудита;
- подготовка признаков и разделение данных по времени на train, validation и test;
- исключение строк с некорректной целевой переменной и формирование признаков без использования будущих значений;
- подбор параметров моделей по validation;
- итоговая оценка выбранных конфигураций на test;
- логирование выполнения скриптов.

Планируется:

- пользовательский интерфейс для анализа показателей и получения прогноза;
- журналирование и просмотр операционных событий в интерфейсе;
- симуляция поступления новых данных и контроль изменений данных и целевого процесса;
- хранение данных в SQLite, если оно потребуется для работы интерфейса.

Автоматическое переобучение при обнаружении дрейфа не планируется: обновление и контроль данных будут демонстрироваться в симуляционном режиме.

## Данные

Для проекта генерируются синтетические демонстрационные данные за 2018–2025 годы:

- ежедневные наблюдения по 16 объектам и 8 категориям отходов;
- операционные события в формате JSON Lines;
- целевой показатель `target_tons` — масса отходов в тоннах;
- показатель мощности объекта — `capacity_tons_per_day`.

Данные предназначены для учебной демонстрации и не являются официальной статистикой. Скрипт генерации не перезаписывает уже существующие файлы.


## Порядок запуска

Скрипты запускаются из корневой папки проекта:

```powershell
python bootstrap.py
python generate_demo_data.py
python validate_raw_data.py
python prepare_model_data.py
python compare_models.py
```

`bootstrap.py` создаёт или проверяет необходимые каталоги и проверяет настройки.

`generate_demo_data.py` создаёт исходные демонстрационные данные, если соответствующих файлов ещё нет.

`validate_raw_data.py` проверяет исходные файлы и формирует отчёт аудита.

`prepare_model_data.py` формирует признаки и временные выборки. При разделении сохраняется хронологический порядок: более поздние данные не попадают в train.

`compare_models.py` перебирает заданные значения гиперпараметров, выбирает лучшую конфигурацию каждого семейства по validation MAE, затем обучает семейные финалисты на train и validation и оценивает их на test. Test не используется для выбора гиперпараметров.

## Сравниваемые модели

Скрипт сравнивает семь семейств моделей:

- недельный наивный прогноз по `target_lag_7`;
- Ridge Regression;
- Elastic Net;
- дерево решений;
- Random Forest;
- Extra Trees;
- HistGradientBoosting;
- Gradient Boosting.

В число семейств входят базовый прогноз и шесть алгоритмов машинного обучения.

Для перебора гиперпараметров используется полный перебор комбинаций значений, заданных для каждого семейства. Все конфигурации оцениваются на validation. Итоговые метрики на test рассчитываются для лучшей конфигурации каждого семейства.

## Оценка качества

Для моделей рассчитываются:

- MAE;
- RMSE;
- WAPE;
- R²;
- среднее смещение прогноза;
- суммарный недопрогноз;
- суммарный перепрогноз;
- MAE загрузки в процентных пунктах, если в данных доступен показатель мощности.

Текущая оценка представляет собой скользящий прогноз на один шаг вперёд по временным выборкам. Она не является отдельным прогнозом на фиксированный горизонт в семь дней.
